# Memory Game

This is a simple memory game built with HTML, CSS, and JavaScript. The goal of the game is to match all the pairs of colored blocks before the time runs out.

## How to Play

1.  **Generate the blocks:** Click the "Generate" button to create a new set of colored blocks.
2.  **Start the game:** Click the "Start" button to begin the timer and enable the blocks.
3.  **Match the blocks:** Click on two blocks to reveal their colors. If the colors match, the blocks will remain visible. If they don't match, they will be hidden again after a short delay.
4.  **Win the game:** Match all the pairs of blocks before the time runs out to win the game.
5.  **Lose the game:** If you run out of time or hearts, you will lose the game.

## Setup

To run the game locally, simply open the `Index.html` file in your web browser.

## Code Overview

*   **`Index.html`:** The main HTML file for the game. It contains the structure of the game board and the UI elements.
*   **`style.css`:** The CSS file for the game. It contains the styles for the game board and the UI elements.
*   **`index.js`:** The JavaScript file for the game. It contains the game logic, including generating the blocks, handling user input, and tracking the game state.
